# 产品详情页数据责任与聚合规则

## 一、基本原则

产品详情页不是一张独立维护的数据表，而是以完整料号为入口，实时聚合CRM产品数据、系列公共资料、商城系统、设计工具和内容关联数据。任何字段只能有一个权威来源，禁止在产品详情页重复录入。

CRM只向官网同步事业部决定展示的产品。前台产品集合必须以本次CRM同步结果为准，不能从系列资料、AI关键词或其他补充表反向生成产品。某个料号停止同步后，其补充数据保留但不调用；重新同步后按稳定料号自动恢复。某系列没有任何同步料号时，系列资料同样保留但不在前台展示。

## 二、页面区域与权威来源

| 页面区域 | 权威来源 | 关联键 | 后台规则 |
|---|---|---|---|
| 产品线、系列、完整料号、封装、全生命周期状态 | CRM系统 | 完整料号 | 只读同步 |
| 电压、容量、温度、寿命、ESR等详细参数 | CRM系统 | 完整料号 | 按产品线确认字段模板完整展示，空值保留 |
| 本料号尺寸（mm） | CRM产品参数 | 完整料号 | 从直径、长、宽、高、厚度、间距等确认字段自动提取 |
| 本料号纹波参数 | CRM产品参数 | 完整料号 | 从额定纹波、ESR及频率等确认字段自动提取 |
| AI搜索关键词 | 官网产品扩展数据 | 完整料号 | 可批量导入，前台隐藏，不覆盖CRM产品字段 |
| 商城商品链接 | 商城系统 | 完整料号 | 只匹配同料号上架商品，可一对多；没有匹配时隐藏 |
| 系列产品主图 | 系列公共资料 | 产品线+系列代码 | 系列下全部料号继承 |
| 系列规格书PDF | 系列公共资料 | 产品线+系列代码 | 替换文件后同系列全部料号同步 |
| 编码规则 | 系列公共资料 | 产品线+系列代码 | 系列下全部料号继承 |
| 特性标签 | 系列公共资料 | 产品线+系列代码 | 展示在料号下方，不进入详细参数表 |
| 产品尺寸图 | 系列公共资料 | 产品线+系列代码 | 独立图片字段，系列下全部料号继承 |
| 纹波电流与频率条件图 | 系列公共资料 | 产品线+系列代码 | 独立图片字段，系列下全部料号继承 |
| 3D-CAD | CAD模型文件库＋料号映射表 | CAD模型ID→多个完整料号 | 模型文件只维护一份；已确认映射直接进入资源，没有映射时进入申请页 |
| 寿命推算 | 寿命公式库 | 产品线+封装/结构 | 仅正式启用公式覆盖的产品显示可用状态 |
| SPICE模型 | SPICE资源库 | 待确认 | 当前只保留入口，不保存演示数据 |
| 可靠性实验数据 | 可靠性资源库 | 待确认 | 当前只保留入口，不保存演示数据 |
| 替代料/交叉参考 | 替代料关系 | 永铭完整料号 | 只展示已确认关系 |
| 推荐应用 | 应用终端推荐料号关系 | 完整料号 | 应用中心只维护终端和完整料号，产品展示参数读取产品中心；由关系反向生成，无关系时隐藏 |
| 推荐新闻和知识文章 | 内容关联关系 | 完整料号或明确的系列范围 | 文章、关系和目标均有效时展示；无关系时隐藏 |
| 打印与参数下载 | 页面聚合服务 | 完整料号 | 使用当前有效数据实时生成，不单独维护 |

## 三、系列公共资料字段

每个系列至少预留以下独立字段：系列名称、产品线、系列产品图片、系列规格书PDF、编码规则文件、特性标签、产品尺寸图、纹波电流与频率条件图、发布状态、版本、更新时间和维护人。

产品尺寸图和纹波电流与频率条件图必须分别上传，不能合并为一个含义不清的“系列技术图片”字段。

## 四、商城匹配规则

1. 商城系统向官网同步平台、商城商品编号、永铭完整料号、商品链接、上架状态和同步时间。
2. 官网只使用完整料号完全相同且状态为上架的记录。
3. 一个永铭料号可同时匹配多个商城平台。
4. 商城商品下架后，产品详情页对应平台链接自动消失。
5. 没有任何有效商城链接时，产品详情页不显示网销商城模块。
6. 官网后台不人工拼接商城URL，不把商城链接写入CRM产品主数据。

## 五、完整性检查

后台应按料号输出完整性结果：CRM字段完整度、系列产品图、系列PDF、两类系列技术图片、编码规则、特性标签、AI关键词、商城匹配、CAD、寿命公式、替代料、推荐应用和推荐内容。CRM空值仍保留；非必选关联没有数据时不报错，前台隐藏对应模块。

## 六、应用中心推荐料号取值

应用中心只保存应用终端ID、永铭完整料号、推荐理由、排序和关系状态。前台展示的完整料号、电压、容量、工作温度、寿命、尺寸、ESR、额定纹波电流和全生命周期状态必须实时读取产品中心。产品中心参数更新后应用中心自动同步，应用中心不得覆盖或补写CRM产品参数。
