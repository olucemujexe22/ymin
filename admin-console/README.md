# 永铭新官网运营后台原型

本目录是基于《新官网后台建设详细需求说明》重新设计的统一后台原型，旧的 `product-admin` 仅保留作历史参考，本原型未复制旧页面结构或代码。

## 访问方式

在项目根目录启动静态服务后访问：

`http://127.0.0.1:4174/admin-console/`

后台演示数据使用浏览器 `localStorage` 保存，不会修改官网正式数据、产品数据库或旧后台备份。

## 已覆盖模块

后台按维护责任分为两个页面工作区：

- 日常运营：维护结构化数据、文件、图片、文章、业务关系与发布状态。
- 前端页面管理：定位具体前台页面和关联代码，记录样式、页面结构、固定文案、跳转与交互修改需求，由IT实施。

数据导入导出、权限和日志作为两类工作区共用的公共管理能力。审批流程不在当前演示版中预设，由数字智能部结合正式权限体系确定。

固定标题、模块说明、按钮文字等低频且与布局紧密相关的内容归入前端页面管理；新闻、FAQ、产品、应用、下载资料、证书、岗位等可结构化业务内容归入日常运营。

- 首页日常运营：首页轮播图片、文案、跳转、语言、排序与发布状态
- 前端页面管理：全站页面定位、前端修改需求、首页结构版本、导航页脚结构、固定页面与多语言页面规则
- 产品中心：CRM产品料号数据、AI搜索关键词、系列公共资料、商城同料号匹配、替代料关系
- 应用中心：应用领域、终端详情与模板、终端推荐料号、应用指南关联
- 服务支持：文章发布、新闻中心重点文章、FAQ知识库、下载中心、合规证书、内容关联中心
- 设计工具：工具总览、寿命公式、3D-CAD模型与申请、SPICE模型、可靠性实验数据
- 咨询与表单：国际咨询、设计工具信息验证和联系我们等表单记录
- 关于永铭：公司内容、企业荣誉、代理商、招聘、原材料采购
- 系统管理：多语言、数据导入导出、角色权限、操作日志

## CRM账号权限与中英文维护

正式系统只有一个后台。中文运营、英文运营和IT管理员登录同一地址，CRM根据账号权限返回不同的菜单、数据范围、编辑字段、上传入口和预览站点，不由用户在内容编辑时手工选择十余种语言。

原型右上角的“演示账号视角”仅用于向数字智能部说明权限结果；正式系统登录后自动确定，不保留人工切换入口。

### 中文官网运营人员

- 当前维护站点固定为“中文官网”，内容版本固定为“简体中文”。
- 维护中文首页、中文新闻与FAQ、中文下载文件，以及加入我们、原材料采购等中文专属页面。
- 可查看产品、系列、应用、CAD和关联关系等全站共享数据；是否可修改共享关系由CRM权限单独控制。
- 不显示国际版专属表单、其他语言包、前端代码定位和系统权限配置。

### 国际官网运营人员

- 当前维护站点固定为“国际版官网 / English Base”，内容版本固定为“English”。
- 维护国际版首页、英文新闻与FAQ、英文下载文件和国际咨询。
- 不显示加入我们、原材料采购等中文专属页面。
- 其他语言不逐条维护，统一读取确认后的英文内容和国际版页面结构，再由翻译包生成；国际运营可查看同步与抽检状态。

### IT/全站管理员

- 可查看中文、英文和共享数据，并管理页面定位、前端修改需求、权限、日志及翻译包状态。
- 前端样式、页面结构、固定文案、导航和页脚差异统一进入“前端页面管理”，不混入日常运营菜单。
- 正式权限、数据审批和技术发布流程由数字智能部结合CRM账号体系实现，本原型不预设审批页面。

### 数据拆分边界

- 中英文分别维护：Banner、首页指标与卡片、文章正文、FAQ正文、下载文件、低频页面文案。
- 中文专属：加入我们、原材料采购。
- 国际版专属：国际首页结构、国际页脚、国际应用咨询表单和国际联系方式。
- 全站共享：产品与系列ID、完整料号、应用领域与终端ID、CAD映射、替代料、推荐料号、文章与产品/应用关系。
- 系列资料的结构和系列ID共享，但产品图、PDF、编码规则、尺寸图、纹波图和特性标签允许分别保存中文与英文版本；没有单独版本时由正式系统按规则回退到共享文件。

中文与英文文章版本使用不同的正文记录，但必须保存同一个稳定内容ID。文章与产品、应用、FAQ的关系只关联稳定内容ID，禁止为英文版重复建立一套关系。

## 核心联动规则

1. 下载中心是公开文件的唯一主数据源；应用中心指南只保存资源ID。
2. 文件换版保持资源ID不变，应用页面自动获取最新已发布版本。
3. 新闻、FAQ知识、产品和应用使用显式关系记录双向联动。新闻文章固定发布到新闻资讯；文章发布后AI提取FAQ候选，人工确认后单独发布FAQ。
4. 知识库Excel只作为导入和批量维护载体，已发布内容与稳定内容ID才是网站正式数据。
5. 应用终端与产品的关系统一精确到完整料号，并以应用中心确认数据表为正式来源。
6. 没有有效关联内容时，前台隐藏对应推荐模块。
7. 首页轮播图的左侧功能区按Banner记录配置；当前产品组合Banner显示，无人机和机器人Banner隐藏，调整排序不改变绑定关系。
8. 首页数据指标按独立记录维护，展示数值、说明文字、排序和发布状态均可修改；停用记录不在前台展示。
9. 首页八大产品线卡片按独立记录维护图片、展示名称和简介；产品线绑定单独保存，避免修改展示文字后影响产品中心筛选跳转。
10. 首页“最新动态与技术文章”不保存精选关系，也不设置人工顺序；系统自动读取新闻中心已发布文章，并按发布时间从新到旧展示。标题、列表摘要、图片、日期与详情链接始终读取新闻文章主数据，文章下架后自动从首页移除。文章确认稿有摘要时原样使用，没有摘要时系统截取正文首段作为列表摘要，运营人员不另写导语。
11. 产品主数据由CRM系统只读同步；AI搜索关键词以完整料号独立维护。全量产品导出可供AI参考，关键词导入只读取完整料号、AI搜索关键词和操作类型。
12. 产品主数据严格使用事业部确认的圆形、方形、异形和超级电容字段模板。字段是否展示只由产品线及封装模板决定，不由当前是否有值决定；空值仍保留展示。
13. CRM只同步事业部决定在官网展示的产品。系列资料、AI关键词等补充数据按系列ID或完整料号保留；CRM停止同步某个料号后，相关补充数据自动停止前台调用但不删除，重新同步后自动恢复。
14. 产品详情页的“本料号尺寸”和“本料号纹波参数”均从CRM产品字段中提取展示，不建立第二套可编辑参数。
15. 系列产品图、系列规格书PDF、编码规则、特性标签、产品尺寸图、纹波电流与频率条件图统一归入系列公共资料；CRM当前同步的同系列料号自动继承。
16. 网销商城链接由商城系统同步，以永铭完整料号精确匹配；一个料号可以匹配多个商城平台，无上架同料号时前台隐藏商城模块。
17. 3D-CAD采用“模型文件主档＋料号映射表”：约299个模型文件分别维护，一个模型可显式关联数百或数千个完整料号；AI规格匹配结果可批量导入，产品校验通过并确认后才供前台使用。替换模型文件不会重复维护料号关系。SPICE和可靠性实验数据当前只保留功能入口，未确认数据结构前不放置演示数据。
18. 产品详情页是聚合展示页，不复制来源数据；CRM参数、系列资料、商城链接、设计资源、替代料、应用和文章分别由各自主数据模块负责。
19. 应用中心推荐产品按终端集中维护，一个终端可通过“添加产品”关联多个完整料号。人工添加时可直接输入或粘贴料号，并从CRM当前同步产品中搜索提示；添加顺序自动作为排序并默认发布。批量维护表只预填应用领域、模块、终端ID和名称，一行对应一个推荐料号。
20. 新闻文章使用独立发布编辑器按确认稿原样录入标题和正文，并在同一页面直接选择应用中心展示范围，以及按产品线、系列或完整料号添加产品详情页相关文章关系。官网文章统一作为永铭原创内容发布，不要求维护作者、编辑、文章来源或外部原文链接。确认稿已有摘要时原样保留，没有摘要时系统截取正文首段作为列表摘要。
21. FAQ不是文章的第二个发布频道。AI从已发布文章正文中提取问题、答案和原文片段形成候选，人工确认后单独发布；发布时自动关联来源文章，并继承该文章已经发布且校验通过的产品中心、应用中心关系。
22. 新闻中心重点文章使用独立精选表维护，每种语言最多三篇。精选表只保存文章ID和轮播顺序，添加后直接生效；不再展示时点击移出轮播。标题、摘要、封面、日期和详情链接始终读取文章主数据，文章本身下架后也会自动停止展示。
23. 所有后台字段必须与前端已有展示位置一一对应，不保留“演示概括文案”、前端不存在的上传项或重复文件。应用中心总览页维护标题、介绍、已有分区标题和已关联技术资源；九大应用卡片只维护前端实际展示的简介、标签、底部文字和排序，固定图标由前端样式管理。热门终端从终端详情中选择，设计工具从工具主档中选择，两者均可按语言增加、移出和排序，不限制固定展示数量。技术资源、应用指南等均引用下载中心稳定资源ID，标题、说明、文件不重复维护。
24. 设计工具、服务支持和关于永铭均设总览页维护入口。总览字段仅维护相应HTML中已有的标题、说明、图片、栏目卡片与排序；工具状态与入口读取设计工具数据，服务支持统计与内容读取新闻、FAQ、下载和合规模块，关于永铭的八大产品线读取产品中心，避免重复维护同一份业务数据。前端固定图标、卡片视觉、布局及不存在于页面的字段不放入日常运营后台。
25. 应用中心总览页是固定页面，不设置草稿或下架状态，也不提供新建和批量导入；运营人员编辑现有中文或英文版本后直接保存更新。总览页中的终端和设计工具是否展示，分别由展示清单控制。
26. 固定页面、固定栏目和固定数量卡片不设置草稿或下架：包括首页指标、首页八大产品线、九大应用领域、服务支持/设计工具/关于永铭总览及固定入口。选择型关系使用“添加/移出”，企业荣誉直接保存；首页结构、导航、修改需求、替代料、代理商和招聘使用各自业务状态，不再套用“已下架”。只有文章、FAQ、下载资源、终端、工具及工程数据等确实需要撤销公开内容的模块保留上下架能力。

### 前后台一一对应原则

- 前端每一段可维护文字、每个可替换图片、每个可下载文件、每个推荐/跳转关系，后台均有且只有一个维护来源。
- 后台每一个日常运营字段都必须能够在前端页面找到对应展示位置；没有展示位置的视觉样式、固定图标、布局代码统一归入“前端页面管理”，不混入运营表单。
- 下载资料、系列资料、CAD模型、文章、FAQ、终端推荐料号等均以稳定ID作为唯一来源；前端只读取ID关系，不复制文件或另写相同说明。
- 产品中心主数据例外：完整料号及确认字段由CRM只读同步；官网后台只维护系列公共资料、AI搜索关键词和业务关联。字段为空仍按事业部确认模板在前端展示。

## 大批量内容关联

日常文章关联已合并到文章发布页面，不要求运营人员理解目标ID、生效范围或影响数量。大量历史数据或跨多篇文章的关系统一在“内容关联中心（批量维护）”使用CSV/Excel模板导入；导入数据先校验并保存为草稿，不直接覆盖已发布关系。

详细规则见 `ASSOCIATION_MODEL.md`。

## 正式系统实施边界

原型用于确认页面、字段、操作和联动规则。数字智能系统正式开发时，需要把本地演示数据替换为正式数据库、文件存储、CRM接口、权限、操作日志、病毒扫描和缓存刷新服务。
