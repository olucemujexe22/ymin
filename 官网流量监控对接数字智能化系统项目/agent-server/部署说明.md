# 流量分析智能体 — 部署说明

---

## 文件清单

```
agent-server/
├── 01-setup.sql          ← 在 PHPMyAdmin 中执行
├── package.json
├── .env                  ← 修改数据库密码后使用
├── server.js             ← 主服务（API 路由）
├── db.js                 ← MySQL 连接
├── baiduApi.js           ← 百度统计 API
├── deepseekApi.js        ← DeepSeek 大模型
├── alerts.js             ← 预警规则引擎
├── fetchData.js          ← 定时拉取百度数据
└── checkAlerts.js        ← 定时预警检测

traffic-agent-demo.html   ← 智能体前端页面（部署为 agent/index.html）
agent.png                ← 智能体头像
```

---

## 部署步骤

### 1. 数据库建表

PHPMyAdmin → `yongming` → SQL → 粘贴 `01-建表.sql` 全部内容 → 执行

### 2. 上传后端代码

```bash
# SSH 连上服务器
cd /www/wwwroot/www.ymin.com

# 上传整个 agent-server 目录
# （宝塔面板 → 文件 → 上传，或 scp）
```

### 3. 安装依赖 & 配置

```bash
cd /www/wwwroot/www.ymin.com/agent-server
npm install

# 编辑 .env，填上 MySQL 密码和百度统计站点ID
vi .env
```

### 4. 启动后端服务

```bash
# 安装 PM2
npm install -g pm2

# 启动
pm2 start server.js --name agent-server
pm2 save
pm2 startup
```

### 5. 部署前端页面

```bash
# 宝塔面板 → 文件 → 进入 /www/wwwroot/www.ymin.com/public
# 新建目录 agent
mkdir -p /www/wwwroot/www.ymin.com/public/agent

# 上传文件到 agent/ 目录：
# traffic-agent-demo.html → agent/index.html
# 小铭同学.png         → agent/小铭同学.png
```

### 6. Nginx 配置

编辑 `/www/server/panel/vhost/nginx/www.ymin.com.conf`

在 `server {` 块内，第一个 `location /` 之前，加入：

```nginx
# ===== 流量分析智能体（agent） =====
# /agent/ 子目录不走 ThinkPHP 框架
location ^~ /agent/ {
    root /www/wwwroot/www.ymin.com/public;
    index index.html;
    try_files $uri $uri/ /agent/index.html;
}

# API 反向代理到 Node.js 后端
location ^~ /api/ {
    proxy_pass http://127.0.0.1:5000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_read_timeout 60s;
    proxy_connect_timeout 10s;
}
# ===== 流量分析智能体 结束 =====
```

重载 Nginx：
```bash
nginx -t && nginx -s reload
```

### 7. 宝塔定时任务

宝塔面板 → 计划任务 → 添加：

| 任务名称 | 执行周期 | 脚本 |
|---------|---------|------|
| 拉取百度流量数据 | 每天 2:00 | `cd /www/wwwroot/www.ymin.com/agent-server && /usr/local/bin/node fetchData.js` |
| 运行预警检测 | 每天 3:00 | `cd /www/wwwroot/www.ymin.com/agent-server && /usr/local/bin/node checkAlerts.js` |

### 8. 验证

```bash
# 检查后端
curl http://127.0.0.1:5000/api/health

# 浏览器访问
# https://www.ymin.com/agent/
```

---

## 首次使用

部署完成后，先手动拉一次数据：

```bash
cd /www/wwwroot/www.ymin.com/agent-server
node fetchData.js
node checkAlerts.js
```

然后浏览器打开 `https://www.ymin.com/agent/`，给小铭同学发一条消息测试。
